# 功能、使用条件与边界

本页区分已有代码路径与使用前提。表格不是“所有设备和服务已通过”的认证；当前公开快照的实际检查以 [VALIDATION](VALIDATION.md) 为准。

## 13 类来源

类型与表单定义在 `SourceProfiles.ets`，调用通过 `MediaServiceRegistry` 分派。完整 URL 可携带合法的反代子路径，真实凭据只在应用内配置。

| 类型 | 目录/文件与认证 | 主要限制 |
| --- | --- | --- |
| Emby | 账号密码或访问令牌与用户 ID；媒体库、详情、分集、字幕、收藏、进度 | 协议、权限、反代和媒体需按实际服务核对 |
| Jellyfin | 独立适配项；标准认证后读取媒体库验证会话 | 不使用飞牛登录或播放端点；服务版本差异仍需测试 |
| Plex | 访问令牌；库、搜索、分集和进度 | 不以其他服务密码替代令牌；不承诺所有转码配置 |
| 飞牛影视 | 兼容目录与 Range 播放路径 | 目录/流鉴权按飞牛边界处理，兼容目录 ID 不视为通用原生文件 ID |
| 飞牛影视（原生） | 兼容目录与独立原生播放会话 | 首次需取得原生会话；保存目录登录不代表原生播放已可用 |
| WebDAV | 账号密码或匿名；真实目录和文件 | 需要实际读取权限；不虚构海报、分集或远端收藏 |
| CloudDrive2 | gRPC-Web 令牌直连；可选 WebDAV 聚合 | 需匹配接口和有效令牌；聚合入口需自行启用 |
| 光鸭云盘 | Client ID、用户访问/刷新令牌；可选聚合 | 设备授权需要自有代理，服务端签名秘密保留代理端；起始目录使用真实文件夹 ID |
| 百度网盘 | 用户令牌或自有应用授权；可选聚合 | 应用权限、Client ID/Secret 和授权状态由开放平台决定 |
| SMB | 主机、共享、域及账号或匿名；只读目录和有界读取 | 需要原生 libsmb2；不跟随未知类型/符号链接，不承诺所有 NAS 兼容 |
| IPTV | 用户提供 M3U 和可选 XMLTV EPG | 不内置订阅；没有节目数据时不编造节目单 |
| 自定义媒体库 | HTTP(S) 或已授权本地 JSON 清单；可选聚合 | 清单需包含实际名称、资源和播放字段；本地文件仍遵守授权边界 |
| 本地文件夹 | 系统 Picker 和只读文件权限 | 权限撤销、能力不支持或临时授权过期时需重新选择 |

CloudDrive2、光鸭、百度、SMB 和自定义类型可显式选择聚合模式。该模式连接已存在的 WebDAV 服务，不会因直连失败自动替换成另一套协议或账号。

文件来源的收藏、历史或列表可由本机状态维护；它们不等于远端影视服务的收藏接口。SMB 的目录数量、并发会话与读取窗口，云端目录分页和请求均有上限；超限应显示错误，不静默漏掉条目。

## 播放

播放器有 MPV 与系统 AVPlayer 适配路径，包括网络串流、定位、速度、画面比例、音轨/字幕选择和片尾接播状态机。具体解码能力由内核、媒体与设备共同决定。标准服务的播放信息、飞牛原生会话、SMB loopback Range、本地借用 fd 各有自己的生命周期。

同一集重复 EOF 不能启动多个下一集任务；切集失败保留可重试状态，退出后迟到回调不能再启动播放。源列表与季/集归属必须核对，不能凭相邻卡片顺序推测下一集。

文件格式出现在容器列表中，不代表全部视频/音频编码、HDR、字幕样式和高码率组合均可播放。4K/HDR、音频直通、弱网长时播放和各设备的硬解行为需要专项验收。

## 原生字幕与 AI 字幕

用户可选择播放器可读取的内置字幕或外部文本字幕。AI 配置支持目标语言、翻译服务和转写服务；两者均可使用用户自己的 OpenAI 兼容地址、模型和密钥，允许分别配置。

已有文本字幕时，保留原时轴再翻译；没有可用文本字幕时，可对支持的媒体执行有界音频提取和转写。文本翻译模型不能自动获得语音识别能力，`/models` 返回模型名也不证明服务支持所需转写格式。

翻译约束是逐句忠实表达：保留口头词、重复、未完句与 cue 对应关系，拒绝条数、顺序或 ID 不一致的整批结果。模型仍可能犯错，本项目没有跨语言准确率或实时速度保证。

原生提取有时间、字节、并发与取消预算；大容器的交织数据、seek 索引或网络 Range 能力仍可能导致窗口提取失败。当前边界包括：

- 位图字幕没有 OCR 实现，不能当成普通文本字幕翻译。
- HLS/嵌套清单的原声音频提取没有在当前有界原生输入中实现；独立可用的文本字幕仍可走文本路径。
- 原始字幕没有真实时间边界、ASR 返回无时间戳时，不制造逐字对齐。
- AI 字幕烧录到投屏流、所有投屏接收端的字幕显示未完成通用支持。

## Vision 与服务器保护

Vision 的在看、待看和播放列表按来源及账号存储与查询。切换来源后重建对应状态，锁定或隐藏来源不能泄露其条目；未获取到可靠日期时不把名称或当前时间当作节目日期。完整追更日历仍有继续完善空间。

PIN 是指定服务器的访问保护，不是全应用启动锁。秘密由系统安全存储处理，界面和运行日志仍需避免暴露服务器地址或签名链接。首次空安装仅显示内置演示内容，真实使用需自行配置。

## 视觉、小窗与投屏

界面使用海报取色、可见图片加载、玻璃材质、统一弹层与动效、V 主题启动和下拉 Hero 变换。当前模块声明面向手机和平板；屏幕大小、系统材质分级、减少动态效果及触摸体验需按设备验证。

小窗和投屏代码已有集成入口，PiP 返回、生命周期、真实接收画面、音轨和字幕兼容性不能仅凭按钮存在或 mock 测试宣称通过。本仓库不承诺电视端界面或 Android 安装包。
