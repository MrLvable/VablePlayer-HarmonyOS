# 来源服务边界

`MediaServices` 是页面调用的统一入口。`MediaServiceRegistry.forKind()` 为13类来源分派独立适配器；`forServer()` 只有在用户明确选择且来源支持时才启用 WebDAV 聚合。原来源类型和连接模式仍参与账号身份范围。

目录服务提供媒体库、详情、分集、字幕或远端进度等能力；文件服务返回真实目录与文件，不伪造远端媒体元数据。飞牛兼容目录令牌和原生播放会话分开处理，其他服务不使用飞牛接口。

账号、来源或代际变化后，迟到请求和授权刷新不能回写新配置。播放 URL、请求头、来源 lease 和资源释放由各协议边界管理，不在通用页面中混拼鉴权信息。未实现的能力明确报错，不静默切换协议。

完整调用关系见 [架构](../../../../../../docs/ARCHITECTURE.md)，各类型连接条件与限制见 [功能说明](../../../../../../docs/FEATURES.md)。具体执行结果见公共验证说明；源码存在不代表服务、媒体和设备均已验收。
